# Yue 1.0.1

Tarqatishdan oldingi mayda tuzatishlar.

## Nima o'zgardi

- **Qo'llanma va litsenziya har qanday kompyuterda ochiladi.** Endi o'rnatish papkasida
  `README.html` (rasmli, brauzerda o'qishga qulay sahifa), `LICENSE.txt` va
  `THIRD_PARTY_LICENSES.txt` bor. Avvalgi `README.md` va kengaytmasiz `LICENSE` ba'zi
  kompyuterlarda hech qaysi dasturga bog'lanmagan bo'lib, Windows "qaysi dastur bilan ochilsin?"
  deb so'rardi.
- Start menyusidagi **"Yue — qo'llanma"** va **"Yue haqida"** oynasidagi tugmalar shu fayllarni
  ochadi.
- 1.0.0 dan yangilaganda eski `README.md` va `LICENSE` o'rnatish papkasidan olib tashlanadi.
- O'chirishdagi "Yue ma'lumotlarini ham o'chiraymi?" savoli sinab ko'rildi: "Yo'q" —
  ma'lumotlar qoladi, "Ha" — `%APPDATA%\Yue` o'chadi.

## O'rnatish

1.0.0 ustidan o'rnatsangiz bo'ladi — sozlamalar, vazifalar va xotira saqlanadi. SmartScreen
oynasi chiqsa: **Batafsil** → **Baribir ishga tushirish**.
